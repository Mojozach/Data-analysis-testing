Basketball Player Data Analysis

This project uses Python and Pandas to analyze basketball player statistics. The dataset contains points, rebounds, and assists per game for five basketball players. The program uses filtering, sorting, and aggregation to find information about player performance.

Instructions for Build and Use

Steps to build or run the software:

Make sure Python is installed on your computer.
Install Pandas using pip install pandas.
Open the Quarto file and render it as an HTML document.

Instructions for using the software:

Run the Python code in the Quarto document.
View the basketball player dataset and the analysis results.
Review the results for the highest scorer, players scoring at least 20 points per game, sorted player statistics, and team averages.
